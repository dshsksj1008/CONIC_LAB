# CONIC LAB V6 — 실제 마커 AR 검증판

## 먼저 구분할 것
- `index.html`: 노트북 3D 수학 시연. 카메라 필요 없음.
- `ar.html`: 기존 실물 마커 AR.
- `ar-verify.html`: **실제 스마트폰·iPad의 카메라와 4번 마커를 점검하는 검증 화면.** 마커를 찾지 못한 경우 성공으로 표시하지 않음.
- `markers.html`: 4장 출력.

## 실제 테스트
1. ZIP을 압축 해제하고 전체 파일을 GitHub Pages/Netlify HTTPS에 배포.
2. 인쇄 마커(특히 4번 종합)를 다른 기기 화면 또는 종이에 준비. 카메라를 띄우는 기기에서 자기 자신의 화면 속 마커를 비추기는 어려움.
3. 모바일 Safari/Chrome에서 `https://.../ar-verify.html` 접속. 카메라 권한 허용.
4. 오른쪽 아래 AR 조작 영역이 보이면 **4번 종합 마커**를 비춤.
5. 왼쪽 위 실기기 검증 패널에서 `4번 마커 추적: 실제 감지 이벤트 수신`, `이중 원뿔+절단면`, `투명 재질` 항목 확인.
6. 아래의 `절단각 θ` 슬라이더를 변경. `조작 후 형상 갱신` 횟수가 증가하고 원/타원/포물선/쌍곡선으로 종류가 변경되는지 확인.
7. 1/2/3번 마커도 차례대로 테스트. 렌더링과 수학 조절이 정상인지 확인.

## 주의
- 이 진단판은 **마커를 실제로 인식한 뒤에만** 추적을 통과로 표시함. 개발 환경에서는 물리적 카메라 검증을 하지 못했음.
- 프레임마다 오래 걸리거나 검은 화면이면 AR.js/A-Frame CDN 연결, 카메라 HTTPS 권한, iPad Safari/WebGL 상태를 확인.
- `실물 인쇄 마커만으로 수행평가 실물 교구 최고점`을 보장하지 않음.

## 배포 전 노트북 웹캠으로 검증
- `RUN_AR_TEST_WINDOWS.bat`을 실행하면 Python 로컬 서버를 시작하고 `http://127.0.0.1:8765/ar-verify.html`이 열림.
- 일반적인 Chrome/Edge에서는 `localhost`가 카메라 사용에 필요한 안전한 출처로 취급되므로, 노트북 웹캠 + 인쇄 마커로 시험 가능.
- 노트북에서 AR이 잘되어도 iPad Safari 성공까지 보장하지는 않음. iPad에서는 GitHub Pages HTTPS에 배포한 뒤 재검증.
